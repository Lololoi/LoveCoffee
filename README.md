# LoveCoffee
☕ LoveCoffee — Вебсайт кав'ярні з онлайн-замовленням та адмін-панеллю
LoveCoffee — це легкий, швидкий та адаптивний вебдодаток (Single Page Application), написаний на чистому HTML, CSS та JavaScript. Проєкт реалізує повноцінний інтерфейс для клієнтів кав'ярні (перегляд меню, додавання напоїв у кошик, оформлення замовлення) та вбудовану адміністративну панель для управління замовленнями й меню.

🌟 Основні можливості
🛒 Для клієнтів
Інтерактивне меню: Зручний перегляд кавових напоїв із підрахунком кількості позицій.

Кошик замовлень: Автоматичний розрахунок загальної вартості замовлення.

Форма оформлення: Можливість вибору типу отримання (Самовивіз або Доставка), введення адреси та коментаря.

Збереження стану: Інформація про меню та замовлення зберігається в браузері (localStorage).

Адаптивний та темний режим: Підтримка темної теми оформлення (автоматично за системними налаштуваннями або вручну) та коректне відображення на мобільних пристроях із урахуванням safe-area-inset.

🛠 Для адміністратора
Захищений вхід: Вхід до адмін-панелі за паролем (за замовчуванням: lovecoffee2026).

Прихований доступ: Кнопка «Адмін» активується у шапці сайту лише при додаванні параметра ?admin=1 до URL-адреси.

Управління замовленнями: Перегляд списку замовлень (ім'я, телефон, товари, спосіб доставки, сума) та зміна їхніх статусів (Нове, Готується, Виконано, Скасовано).

Редагування меню: Можливість додавати нові позиції, змінювати назву, опис чи ціну існуючих напоїв, а також видаляти їх у реальному часі.

🛠 Технологічний стек
HTML5 — семантична структура та форми.

CSS3 — CSS Variables (змінні теми), Flexbox, CSS Grid, Media Queries, стилізація під світлу та темну теми.

JavaScript (Vanilla ES6+) — робота з DOM, обробка подій, збереження даних у localStorage, динамічний рендеринг елементів.

Без сторонніх залежностей — проєкт працює «із коробки» без використання фреймворків, збірників чи бібліотек.
